# Проектная работа "SkillSwap"
Выпускная работа по окончанию курса "Яндекс-Практикума" по направлению "Фронтенд-разработка"
## :grey_question: Описание проекта
Интернет-платформа "SkillSwap" позволяет людям обмениваться навыками друг с другом.

## :file_folder: Структура проекта
1. `.husky/` - каталог с Git-хуками (скриптами, которые автоматически запускаются перед коммитом или пушем, например, для проверки кода линтерами).
2. `.storybook/` - каталог с конфигурационными файлами для Storybook (инструмента для разработки и документирования UI-компонентов в изоляции).
3. `public/` - каталог со статическими ресурсами (изображения, шрифты, favicon), которые не проходят обработку сборщиком и копируются в корень итоговой сборки как есть.
6. `src/` - каталог с исходным кодом приложения (компоненты, стили, логика, утилиты).
7. `.gitignore` - файл, в котором перечислены файлы и папки, которые Git должен игнорировать (не отслеживать и не коммитить).
8. `.prettierignore` - файл, указывающий Prettier, какие файлы и папки не нужно форматировать.
9. `.prettierrc` - файл конфигурации Prettier (инструмента для автоматического форматирования кода), задающий правила оформления.
10. `stylelintignore` - файл, указывающий Stylelint, какие файлы и папки не нужно проверять.
11. `.stylelintrc` - файл конфигурации Stylelint (линтера для CSS/SCSS), задающий правила проверки стилей.
12. `README.md` - файл с основной документацией проекта.
13. `commitlint.config.js` - файл конфигурации Commitlint, проверяющего сообщения коммитов на соответствие соглашению о стиле.
14. `eslint.config.js` - файл конфигурации ESLint.
15. `index.html` - главный HTML-файл приложения, который служит точкой входа и подключает скомпилированные скрипты и стили.
16. `package-lock.json` - файл, фиксирующий точные версии всех установленных зависимостей для обеспечения воспроизводимости сборки.
17. `package.json` - главный файл проекта Node.js, содержащий метаданные, список зависимостей и скрипты для запуска задач.
18. `postcss.config.js` - файл конфигурации PostCSS.
19. `tsconfig.app.json` - файл конфигурации TypeScript для исходного кода приложения.
20. `tsconfig.json` - корневой файл конфигурации TypeScript.
21. `tsconfig.node.json` - файл конфигурации TypeScript для файлов, выполняемых в среде Node.js.
22. `vite.config.ts` - файл конфигурации Vite.
23. `vitest.shims.d.ts` - файл с декларациями типов для Vitest, расширяющий глобальные типы TypeScript для корректной работы тестов.
