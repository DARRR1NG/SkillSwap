Начало работы:

1. Склонируйте репозиторий с ветки разработки (develop), выполнив команду: `git clone --branch develop git@github.com:PM-YandexPracticum/SkillSwap_48_2.git`
2. Установите все необходимые зависимости, выполнив команду в терминале проекта: `npm install`
3. Откройте проект в браузере, выполнив команду: `npm run dev`
